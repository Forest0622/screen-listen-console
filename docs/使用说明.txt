屏幕监听控制 · 安装与使用说明
================================

一、安装
  1. 打开这个磁盘映像，把「屏幕监听控制.app」拖到「应用程序」文件夹（旁边那个箭头图标就是）。
  2. 拖完后在「启动台」或「应用程序」里找到它，双击运行。

二、第一次打开可能被系统拦住（正常现象）
  本项目没有 Apple 开发者证书与公证，所以首次打开会被 Gatekeeper 拦。
  处理办法：在 Finder 里右键点「屏幕监听控制」→ 选「打开」→ 弹窗里再点一次「打开」。
  如果没有「打开」选项：系统设置 → 隐私与安全性 → 页面下方「仍要打开」。
  也可以用终端一次性解决：xattr -dr com.apple.quarantine /Applications/屏幕监听控制.app

三、第一次必须先授权「屏幕录制」（每台电脑各授权一次）
  1. 双击打开 App，点「开启服务」。
  2. 弹出授权框时点「打开系统设置」；没弹就直接进 系统设置 → 隐私与安全性 → 录屏与系统录音。
  3. 在列表里找到「屏幕监听控制」：有就打开右侧开关；没有就点列表下方「+」，
     从「应用程序」里选中它添加，再打开开关。
  4. 完全退出 App（⌘Q）再重新打开，点「开启服务」。
  5. 看到「抓屏状态：正常」就说明成功了。

四、运行依赖
  需要 Python 3，macOS 装了「命令行工具」就有。若 App 提示「未检测到 Python 3」，
  在终端执行：xcode-select --install ，装完重开 App。

五、怎么用
  1. 点「开启服务」，窗口里会列出三个访问地址：
     本机   http://127.0.0.1:6080/
     局域网 http://<这台机器的IP>:6080/
     同域名 http://<主机名>.local:6080/
  2. 在同一局域网的其他设备（手机/平板/另一台电脑）用浏览器打开「局域网」那一行。
  3. 账号和密码显示在窗口「设备访问地址」下方，是这台机器第一次运行时随机生成的，
     不是固定值。想换密码：点窗口上的「修改账号密码」，改完点「保存」立刻生效；
     点「随机生成」可以直接换一个 14 位随机密码。忘了密码也可以看
     ~/.remote-view/logs/service.log 里打印的那一行。
  4. 首次连不上：检查这台机器是否弹过「是否允许…接受传入网络连接」，要选「允许」。

六、说明
  · 端口固定 6080，只读查看，不提供鼠标键盘控制。
  · 访问记录存在 ~/.remote-view/logs/ 里（clients.json / access.log）。
  · 不做开机自启；每次手动打开 App 再点「开启服务」即可。
  · 「关闭服务」会立刻释放 6080 端口。
  · HTTP Basic 认证在局域网内是明文传输，请只在可信网络里使用。
